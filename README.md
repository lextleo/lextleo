### `01 / about`

I'm **Aditya**—a robotics engineering student interested in what happens when software meets the physical world.

I like peeling back the layers underneath a working system: the code, the electronics, the math, and the trade-offs that connect them. I'm still learning, and I'd always rather build a small thing I can explain from first principles than a big thing I can't.
