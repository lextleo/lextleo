## `01 / about`

I'm Aditya, a robotics engineering student interested in what happens when **software meets the physical world**.

I like exploring the layers underneath a working system: the code, the electronics, the math, and the decisions that connect them. My interests move between robotics, systems programming, simulation, and machine learning — with open source as a way to make experiments useful to other people.

I'm still learning. I'd rather build a small thing I can explain from first principles than a big thing I can't.

### Line Follower Robot

**A small robot, a lot of things to understand.**

A hardware-learning project using an Arduino Uno, an 8-channel IR sensor array, N20 motors, a TB6612FNG motor driver, and a battery. The real goal is to understand the wiring, sensing, motor control, and debugging — not just assemble the parts.
